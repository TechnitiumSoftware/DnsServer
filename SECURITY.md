# Security Policy

## Supported Versions

Only the latest available version of Technitium DNS Server (i.e. `master` branch) is supported for security updates.

## AI Generated Reports

If you are using AI to do security audits and generating reports without giving a deep thought then please stop. Please realize that several people have already done that and you are probably just reporting duplicate issues, or security issues that do not really exist.

If the issue is related to DNS then make sure that it is correct as it may be just the way DNS is supposed to work. Also, reference any related RFCs that cover DNS issues to support the report.

Submit reports if you believe that you have found something credible and done through analysis of each issue in your report with verification. 

I do not wish to discourage anyone from reporting security issues but it's not practical to operate if several different people everyday are sending a dozen identical AI generated reports each.

Thank you for your co-operation.

## Reporting a Vulnerability

To report a vulnerability send an email to security@technitium.com
