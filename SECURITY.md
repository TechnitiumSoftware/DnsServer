# Security Policy

## Supported Versions

Only the latest available version of Technitium DNS Server (i.e. `master` branch) is supported for security updates.

## AI Generated Reports

If you are using AI to do security audit and generating reports without giving a deep though then please stop. Please realize that several people have already done that and you are probably just reporting duplicate issues, or security issues that do not really exist.

Submit reports if you believe that you have found something credible and done through analysis of each issue in your report. Thank you for your co-operation.

## Reporting a Vulnerability

To report a vulnerability send an email to security@technitium.com
